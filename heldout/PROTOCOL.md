# Held-out set protocol

Goal: a test set you did not write and did not tune against.

1. `python scripts/make_heldout_prompts.py` (builds prompts from the policy documents only).
2. Send each `heldout/prompts/batch_XX.txt` to a model from a **different family than your agent's model**. Collect the JSON lines (about 50 candidates).
3. Do not show the generator `data/manifest.json` or `data/eval/questions.jsonl`.
4. Keep 30-40 questions with a spread of kinds. For each kept question, read the cited documents yourself and confirm the draft answer is right
   (or that abstaining / escalating is right). Fix or drop anything you cannot verify.
5. Convert to the same schema as `data/eval/questions.jsonl` (`split: "heldout"`), save as `data/eval/heldout.jsonl`, commit, and **freeze it**.
6. Run it once, at the end. Report it as its own table next to the main results. Never tune prompts, thresholds or guardrails against it.
7. In the README: "held-out set generated by <model>, blind to the trap manifest, human-verified."
